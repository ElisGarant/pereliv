# Объём MVP (заморожен)

Всё, что не в списке «Делаем», ждёт второй очереди. Новые идеи пишем в конец файла, в MVP не берём.

## Делаем

### Бот (aiogram 3)
- `/start` с реф-кодом: регистрация, реферал закрепляется при первом входе, самореферал запрещён.
- Кнопка «Открыть» Mini App, `/app`, `/help`.
- Уведомления: решение по заявке, новый урок, задание проверено.
- Голосовые и пересланные голосовые → текст (своя расшифровка Whisper на сервере, без ключей).

### Вход новичка
- Бесплатные уроки (2–3), тест на роль (10 вопросов), анкета, статус заявки.
- Повторная заявка через 30 дней после отказа, лист ожидания.

### Академия
- Модули и уроки, открытие по порядку.
- Урок: YouTube-плеер (доступ «по ссылке»), главы, субтитры YouTube, конспект, материалы.
- Личные заметки с тайм-кодами.
- Тест урока: проходной балл, пересдача через N минут.

### Заказы
- Биржа заказов, «Взять заказ», ежедневный отчёт.
- Начисления вручную (админ).

### Профиль
- Данные, роль, направление, реф-ссылка.

### Админка (тот же Mini App)
- Заявки: одобрить / отклонить / лист ожидания.
- Редактор уроков: ссылка YouTube, главы, конспект, тест.
- Люди: список, роль, направление.

## Вторая очередь
План и норма дня, голосовые → задачи и отчёты автоматически, сообщество, разборы недели, дедлайны и штрафы, «Не в строю», шаблоны дня, прогресс учеников, расшифровка ИИ под видео, XP, грейды, сезоны, рейтинг, магазин наград.

## Стек
- `server/app`: FastAPI, SQLAlchemy 2 (async), Postgres в Supabase.
- `server/bot`: aiogram 3, общая база с API.
- `web`: React + Vite + TypeScript, Telegram Mini Apps.
- Авторизация только через Telegram `initData`, подпись проверяется на каждом запросе.
- Права проверяются на бэкенде. В Supabase включён RLS без политик: прямой доступ к таблицам закрыт, ходит только сервер.

## Готово, когда
- Новичок проходит путь от `/start` до одобренной заявки.
- Ученик проходит урок с видео, заметками и тестом, следующий урок открывается.
- Участник берёт заказ и сдаёт отчёт.
- Админ одобряет заявку и публикует урок.
- Тесты бэкенда зелёные, Mini App собирается.

## План по неделям
1. База, авторизация, бот `/start`, вход новичка (API + экраны).
2. Академия: уроки, плеер, заметки, тест. Админка заявок.
3. Заказы и отчёты, редактор уроков, голосовые в боте.
4. Тест с командой, правки, деплой на VPS.
